# Error taxonomy

Choose exactly one primary type:

- `conceptual_misconception`: the learner applies an incorrect definition or model.
- `missing_prerequisite`: a lower-level concept blocks the target; prefer `review_prerequisite`.
- `procedural_error`: the learner knows the concept but performs steps in an invalid order.
- `calculation_error`: the method is appropriate but arithmetic or symbolic manipulation fails.
- `misread_question`: the answer addresses a materially different request.
- `guessing`: the answer is correct but confidence is low or support is absent.
- `none`: the answer is correct and adequately supported.

Resolve ambiguity in favor of the earliest blocking cause. Report only that cause.
